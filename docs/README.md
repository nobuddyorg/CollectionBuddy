# CollectionBuddy documentation

Organised by [Diátaxis](https://diataxis.fr), which splits documentation into four kinds depending on what you're trying to do:

- **Tutorial** — learning by doing, for a first-time run. [Getting started](tutorials/getting-started.md).
- **How-to** — task-oriented recipes for something specific you want to do. [User guide](how-to/user-guide.md) · [Developer guide](how-to/developer-guide.md) (local dev, new environment, deploy).
- **Reference** — technical description of what's there. [Architecture](reference/architecture.md) · [Configuration](reference/configuration.md).
- **Explanation** — the reasoning behind non-obvious decisions. [Design decisions](explanation/design-decisions.md).

For the local dev setup and the checks CI runs before a PR, see [CONTRIBUTING.md](../CONTRIBUTING.md) — the guides here link to it rather than repeat it.
